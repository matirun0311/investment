> 今日のたとえ：📝 通販の「ご注文内容の確認」画面

## 注文画面は、通販の確認画面と同じ

ネット通販で「購入する」を押す前に、商品・個数・支払い方法・届け先を確認しますよね。株の注文画面も、聞かれることはほとんど同じです。

## よくある1株の注文画面（イメージ）

画面の上から順に、だいたいこんな項目が並んでいます。

| 画面の上から | 表示の例 | メモ |
|---|---|---|
| 会社名・コード | 〇〇ホールディングス（1234） | 会社名と背番号 |
| 今の値段 | 現在値 2,000円 / 前日比 +20円 | |
| 取引 | **買い** / 売り | |
| 株数 | **1** 株 | |
| 価格 | 成行 | 1株は成行だけのことが多い |
| 口座 | **NISA（成長投資枠）** / 特定 | |
| 概算代金 | 約2,000円 | だいたいのお会計 |
| 手数料 | 0円 | |
| ボタン | ［注文内容を確認する］ | |

※ これはイメージです。実際の画面は、お店によってちがいます。

## ひとつずつ翻訳

| 画面の言葉 | 翻訳 | 確認ポイント |
|---|---|---|
| 銘柄名・コード | 会社名と背番号 | **買いたい会社とまちがいないか** |
| 取引（買い・売り） | 買うのか、売るのか | 「買い」になっているか |
| 株数（数量） | 何株買うか | **「1」になっているか**（100にしていないか！） |
| 価格（執行条件） | 成行・指値・決まった時間の値段 | お店のルール通りか |
| 口座区分（預り区分） | NISAか特定か | 決めた方になっているか |
| 概算代金（がいさんだいきん） | だいたいのお会計 | **予算以内か** |

## 「株数」の打ちまちがいに注意

いちばん多いまちがいは、**株数の入力** です。1株のつもりで「100」と入れてしまう…ということが起こり得ます。最近は「予算を超えています」と止めてくれるアプリもありますが、**概算代金を見て「あれ、高すぎない？」と気づける** ようにしておきましょう。

## 最後に「暗証番号」

確認画面で、**取引用の暗証番号（パスワード）** を入れて注文を確定するお店が多いです。口座開設のときに決めた番号を準備しておきましょう。

## 今日のひとことまとめ

1. 注文画面は、通販の「ご注文内容の確認」と同じ
2. 会社名・コード・株数（1株か）・口座区分・概算代金をチェック
3. いちばん多いまちがいは株数の入力。概算代金で気づけるように
