> 今日のたとえ：🎓 おこづかい帳から始まった、90日間の卒業式

## 90日間、本当におつかれさまでした！

「株」と聞いて頭がフリーズしていた90日前のあなたは、今、

- 株＝会社の応援チケット、と説明でき
- 自分専用のお財布（口座）を持ち
- 指値・成行、特定口座、NISAの意味がわかり
- （もしかしたら）好きな会社の株を1株持っている

はずです。これは、本当にすごいことです。

## 90日間のふりかえり

| 章 | 学んだこと | キーワード |
|---|---|---|
| 第1章（1〜30日目） | 株の正体とお財布づくり | 応援チケット、3つの袋、特定口座＝自動レジ、NISA＝魔法の宝箱 |
| 第2章（31〜60日目） | お買い物のルールと税金 | 指値＝予約、成行＝今すぐレジへ、約定、受渡日、約20%の税金 |
| 第3章（61〜90日目） | おためし1株デビュー | 毎日使っている会社、含み益・含み損、見すぎ病、自分ルール |

## 卒業チェックリスト

| | チェック項目 |
|---|---|
| □ | 株＝会社の応援チケット、と人に説明できる |
| □ | 「泣かない金額」を自分で決められる |
| □ | 特定口座（源泉徴収あり）とNISAのちがいを言える |
| □ | 指値と成行のちがいを、スーパーのたとえで言える |
| □ | 税金は「もうけの約20%、NISAなら0円」と言える |
| □ | 1株を買った（または、買う手順がわかる） |
| □ | 値下がりしても、あわてて売らない理由を言える |
| □ | 信用取引とSNSのウマイ話には近づかない |

**5つ以上チェックがついたら、卒業です！** 🎉

## これからも続けるための3つの約束

1. **なくなっても泣かないお金で**：生活の袋・もしもの袋には手を出さない
2. **時間を味方に、あわてない**：毎日のデコボコより、長い目で
3. **わからないものは買わない**：説明できないもの、「必ずもうかる」話には近づかない

## さいごに

株は、「お金を増やす道具」であると同時に、**「世の中のしくみを知るための窓」** でもあります。

毎日使っているお店、食べているお菓子、乗っている電車――その向こうには、がんばっている会社と、それを応援している株主たちがいます。あなたも今、その仲間の1人です。

おこづかい帳の延長から始まった90日間。ここからは、あなた自身のペースで、ゆっくり歩いていってください。
