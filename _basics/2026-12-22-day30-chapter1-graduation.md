> 今日のたとえ：📦 ネットで注文した荷物を待つ、あのワクワク期間

## 口座ができるまで、少し待つ

申し込みが終わると、お店で **審査（しんさ）＝申し込み内容の確認** が行われます。

- 証券口座：早ければ **翌日〜数日** で使えるようになることが多い
- NISA口座：お店から税務署へ確認するため、**1〜2週間ほど** かかることも（最近は、確認中でも先に使えるお店も増えています）

## 待っている間の「ワクワク準備」

1. 📱 **証券会社のアプリをダウンロード** しておく（ログインはまだできなくてもOK）
2. 🛒 **身の回りの会社さがし**：家の中のお菓子、ゲーム、洗剤…作っている会社の名前をメモ
3. 👛 **泣かない金額** を確認（10日目）
4. 📰 ニュースで「株価」という言葉が出たら、ちょっと耳をかたむけてみる

## 第1章 卒業チェックリスト

ここまでの30日間、おつかれさまでした！ 次の項目にいくつチェックがつくでしょう？

| | チェック項目 |
|---|---|
| □ | 株＝会社の「応援チケット」だと説明できる |
| □ | 物の値段が上がると、貯金の「買える力」が減ることがわかった |
| □ | お金を「生活・もしも・応援」の3つの袋に分けた |
| □ | 自分の「泣かない金額」を決めた |
| □ | 株は「証券会社」というお店で買うとわかった |
| □ | お店（ネット証券）を1つ決めた |
| □ | 「特定口座（源泉徴収あり）」＝税金の自動レジ、と言える |
| □ | 「NISA」＝税金がかからない宝箱、と言える |
| □ | 口座開設を申し込んだ |

**6個以上チェックがついたら、大成功です！** 口座の申し込みがまだの人も、あせらなくて大丈夫。第2章を読みながら、準備ができたタイミングで申し込みましょう。

## 第2章の予告

明日からは **第2章「お買い物のルール」** です。株の売り場が開いている時間、「指値・成行」という注文のしかた、会社からのお礼、税金のしくみを、スーパーのお買い物にたとえて学びます。

## 今日のひとことまとめ

1. 口座ができるまで、数日〜2週間くらい待つことがある
2. 待ち時間は、アプリの準備と「身の回りの会社さがし」を
3. 第1章卒業おめでとう！明日からは「お買い物のルール」
