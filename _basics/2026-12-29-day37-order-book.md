> 今日のたとえ：🧍🧍🧍 「この値段なら買う」「この値段なら売る」人の行列

## アプリの「板」という表

会社のページを見ていると、数字が上下にずらっと並んだ表があることがあります。これを **板（いた）** または **気配（けはい）** と言います。

- **板**　＝　「この値段で売りたい人」と「この値段で買いたい人」が、何株分並んでいるかの **行列表**

## 板のイメージ

| 売りたい株数 | 値段 | 買いたい株数 |
|---|---|---|
| 300 | 1,003円 | |
| 500 | 1,002円 | |
| 200 | 1,001円 | |
| | 1,000円 | 400 |
| | 999円 | 600 |
| | 998円 | 100 |

- 上半分：**売りたい人の行列**（1,001円なら売るよ、という人が200株分など）
- 下半分：**買いたい人の行列**（1,000円なら買うよ、という人が400株分など）

今、「1,001円で売りたい人」と「1,000円で買いたい人」がにらめっこしている状態です。

## お買い物が成立する瞬間

ここに、「1,001円でいいから買います！」という人が来たら？ → 売りたい人の行列の先頭（1,001円）とぴったり合って、**お買い物成立** です。

これが、毎日何万回、何百万回とくり返されて、株価が少しずつ動いていきます。

## 今は「見なくてもいい」

板は、プロや慣れた人がよく見る表です。初心者は **「こういう行列表があって、そこで値段が決まっているんだな」** とわかれば十分です。

また、1株（バラ売り）のサービスでは、板を気にせず買えるしくみのお店も多いです。

## 今日のひとことまとめ

1. 板＝「この値段で売りたい・買いたい」人の行列表
2. 売りたい値段と買いたい値段が合うと、お買い物が成立する
3. 初心者は「こんな表がある」と知っておくだけでOK
